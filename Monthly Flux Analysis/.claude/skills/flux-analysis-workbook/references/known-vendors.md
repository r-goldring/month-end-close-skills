## Bill Number / Doc Number Decoder

| Pattern | Means |
|---|---|
| `A-2XXXXX` | Uruguay Medical Vendor (Uruguay medical) vendor bill |
| `JE#####` / `JE20XXX` | Internal JE; cite memo, not JE number |
| `Mar2026_Medical Carrier A` / `Apr2026_Medical Carrier A` | Medical Carrier A monthly medical premium |
| `55810_MMDDYYYY` | Dental Vision Provider monthly dental/vision premium |
| `ACH_Debit_MM.DD.YYYY_*` | Direct ACH wire (LOANINT for term loan, Barclays for UK wires, etc.) |
| `INV-1XXXX` | Survey Translation Vendor invoice |
| `26-8XXXX` | Paper Survey Vendor invoice |
| `DEP8XX` | NetSuite deposit record number |
| `2026-{MM}-ACCRUALS` | Monthly accrual JE external ID |
| `2026-{MM}-SW-RECLASS` | Monthly software dept-reclass JE external ID |
